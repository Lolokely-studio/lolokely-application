## Project Description

Lolokely is a full-stack web application that combines **task management** capabilities with an **AI-powered social media post generator**. It's designed for teams to collaborate on tasks while also providing tools for creating engaging social media content.

### Key Features

- **Task Management**: Create, assign, and track tasks with subtasks
- **Team Collaboration**: Assign tasks to multiple team members
- **AI-Powered Post Generation**: Generate social media posts using Google Gemini AI
- **Real-time Notifications**: Get notified about task assignments and updates
- **User Preferences**: System learns from your choices to improve suggestions

## Technology Stack

### Backend
- **Framework**: Flask (Python)
- **Database**: PostgreSQL (Supabase)
- **Authentication**: JWT (Flask-JWT-Extended)
- **AI Integration**: Google Generative AI (Gemini)
- **Validation**: Marshmallow

### Frontend
- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router
- **HTTP Client**: Axios
